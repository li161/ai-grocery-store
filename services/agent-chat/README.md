# Pi Agent 群聊 API

## 本地启动
1. 在运行后端的主机安装并登录 Pi CLI，确认终端中 `pi -p "你好"` 可正常执行。
2. 在本目录执行 `npm start`，默认监听 8787 端口。
3. 打开 AI 杂货铺「数字人群聊」，切换到 Pi Runtime，填写此服务地址。

## 部署
GitHub Pages 只能托管 Vue 前端，不能运行常驻 Node 服务或 Pi 进程。将本目录部署到支持 Node.js 且已安装/认证 Pi 的主机；设置 `ALLOWED_ORIGIN` 为前端真实来源，然后在界面填入后端公开地址。不要把模型密钥写入 Vite 前端变量。

## MVP 边界
- 每个选中角色独立启动一次 Pi CLI，并发运行。
- 每个调用有超时，单个 Agent 失败不会丢弃其他成功结果。
- 当前是单进程原型；公开部署前应增加鉴权、限流、持久化和更严格的来源校验。
- 本后端假设已安装的 Pi CLI 支持 `pi -p`，需在目标主机验证 CLI 参数。
